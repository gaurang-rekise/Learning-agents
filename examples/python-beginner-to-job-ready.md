# Example: Python Beginner to Job-Ready

## Learner request
I know basic computer usage but not programming. I want to become job-ready for junior Python automation roles in 6 months with 8 hours per week.

## Expected orchestration
1. `autonomous-curriculum-architect` profiles the learner and creates a 24-week roadmap.
2. `diagnostic-assessment-agent` checks math, logic, command-line, and problem-solving prerequisites.
3. `learning-resource-researcher` recommends beginner Python, Git, testing, automation, and portfolio resources.
4. `practice-project-generator` creates weekly coding drills, automation scripts, and capstone projects.
5. `progress-mentor-agent` reviews quiz/project evidence every 2 weeks and adjusts pacing.
6. `socratic-tutor-agent` is used for concepts the learner struggles to explain back.
