# Install scripts

This folder installs the Learning Agents pack into another AI-agent workspace.

The installer copies the reusable pack into `.learning-agents/` in the target workspace and writes provider-specific context files for OpenAI-compatible agents, Claude agents, Gemini, and Google Antigravity.

## Quick install

From this repository, run one of:

```bash
install/install_openai.sh --target /path/to/your/workspace
install/install_claude.sh --target /path/to/your/workspace
install/install_gemini.sh --target /path/to/your/workspace
install/install_antigravity.sh --target /path/to/your/workspace
```

Or install all provider integrations:

```bash
install/install_learning_agents.sh --provider all --target /path/to/your/workspace
```

On Windows PowerShell, use:

```powershell
pwsh install/install_learning_agents.ps1 -Provider all -Target C:\path\to\your\workspace
```

## Provider outputs

| Provider | Files created in target workspace |
| --- | --- |
| OpenAI-compatible agents | `.learning-agents/`, `AGENTS.md` |
| Claude agents | `.learning-agents/`, `CLAUDE.md` |
| Gemini | `.learning-agents/`, `GEMINI.md`, `.gemini/settings.json` |
| Google Antigravity | `.learning-agents/`, `GEMINI.md`, `.gemini/settings.json`, `.antigravity/workflows/learning-agents.md` |

## Safety behavior

- The `.learning-agents/` pack is refreshed on every install.
- Existing provider files are backed up before replacement unless they were already generated by this installer.
- Use `--force` to overwrite generated provider files.

## After installation

Ask your agent tool to read its provider context file, then provide a learner request with:

- topic
- target outcome
- current level
- deadline or time horizon
- weekly time budget
- preferred formats
- constraints

Example request:

```text
Use the installed Learning Agents pack.
Topic: cloud security
Target outcome: prepare for an entry-level cloud security role
Current level: basic Linux and networking
Time budget: 8 hours/week for 4 months
Preferred format: hands-on labs and docs
Create diagnostics, curriculum, resources, projects, and progress checks.
```
