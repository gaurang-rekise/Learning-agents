# Drills

Speed and repetition sheets, per `pedagogy/formats/drill.md`.

One file per drill, named `<drill-id>.md`. Each carries its target, its baseline,
its best qualifying run, its items, and a dated run log.

**Rules that matter most:**
- Never drill a node that lacks `understanding` in `../mastery.md`.
- Record a **baseline** before setting a target.
- Accuracy floor (>=85%) before pushing the clock.
- Fluency counts only when the target is hit on a **later day** — then mark
  `practice` in the mastery ledger and **retire the drill**.
