# Learner Record Templates

Blank scaffolds the installer copies into a fresh workspace, so a new learner's
`learner_records/` exists from the first session rather than being conjured
mid-conversation.

| Template | Becomes |
|---|---|
| `profile.md` | `learner_records/profile.md` |
| `roadmap.md` | `learner_records/roadmap.md` |
| `mastery.md` | `learner_records/mastery.md` |
| `deck.md` | `learner_records/deck.md` |
| `session.md` | `learner_records/sessions/YYYY-MM-DD_sessionN.md` |

Replace every `<angle-bracketed>` placeholder. Delete nothing structural —
the section headings are a contract the hooks and agents read.
