---
description: Start or continue a teaching session against learner_records/
argument-hint: [topic or node — omit to continue from the last session]
---

Run a full teaching session using the `teach` skill.

Topic or node: $ARGUMENTS

If no topic was given, continue the course: execute the `Next Session Entry Point` from the most recent session log in `learner_records/sessions/`.

Run all five phases from `pedagogy/session-shape.md` — restore, probe, plan, teach, checkpoint. Do not skip the probe because the topic seems familiar, and do not skip the checkpoint because the session ran short.
